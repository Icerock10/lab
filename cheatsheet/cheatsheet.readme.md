# HTML

## Semantic tags:

```html
<header> | <footer> | <nav> | <aside> | <main> | <section> | <article>

<details> | <summary> | <figure> <figcaption> </figure> |

<dialog> (modal) | <address> (contact details) | <blockquote> (citation) | <time datetime="2025-02-05">05 February</time>
```

## HTML Attributes:

- `[data]`

```html
<div data-user-id="123"></div>
element.dataset.userId // 123
```

- `[tabIndex]`

```html
<div tabindex="-1"></div>
// Never gets focus with Tab
<div tabindex="0"></div>
// First in line
```

- `<input>`

```CSS
input[type='text'][required][disabled][data-id='12'][autocomplete="off"][name^="user"]
```
