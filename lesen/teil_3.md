# 📖 Lesen Teil 3 – Wortschatz und Strategie
 
## 1. Was bedeuten die Wörter? Ordnen Sie zu.
 
| Wort | Erklärung |
|---|---|
| die Geburtsbescheinigung | Darin wird bescheinigt, dass ein Kind geboren wurde. |
| das Zwischenzeugnis | Das ist nützlich, wenn man eine neue Arbeitsstelle sucht oder in Elternzeit gehen möchte. |
| der Einkommensnachweis | Damit kann man nachweisen, wie viel man verdient. |
| die Arbeitgeberbescheinigung | Damit bestätigt der Arbeitgeber etwas, z. B. seit wann man in der Firma beschäftigt ist. |
| die Krankenkassenbescheinigung | Damit kann man belegen, wo man krankenversichert ist. |
| der Mindestbetrag | Das ist das Minimum an Geld, das man bekommt oder bezahlen muss. |
| der Kündigungsschutz | Dieses Recht schützt Beschäftigte davor, ihre Arbeit zu verlieren. |
| das Sorgerecht | Dieses Recht haben Eltern für ihre Kinder. |
| der Tarifvertrag | Vertrag zwischen Gewerkschaft und Arbeitgeber(verband), der Löhne und Arbeitsbedingungen für eine Branche regelt. |

## 2. Strategie: Schritt für Schritt
 
### Zuordnung (Situationen → Texte)
 
1. Lesen Sie die Situation und unterstreichen Sie: **Wer?** **Was will die Person?** **Welche Bedingung?** (z. B. Arbeitnehmer, Probezeit, will kündigen)
2. Notieren Sie 2–3 Schlüsselwörter und überlegen Sie sich Synonyme.
3. Überfliegen Sie die Texte (**Skimming**): Worum geht es in jedem Text? Geben Sie jedem Text ein Stichwort (Urlaub / Kündigung / Überstunden …).
4. Suchen Sie 1–2 passende Kandidaten und lesen Sie dann gezielt die passende Stelle genau (**Scanning**).
5. Prüfen Sie die Bedingung vollständig: Das Thema passt, aber passt auch die Bedingung (Frist, Personengruppe, Ausnahme)?
6. Passt kein Text und gibt es die Option **x**, wählen Sie **x**. Nichts erzwingen.
7. Ein Text passt nur zu einer Situation (nach den Prüfungsbedingungen prüfen).
